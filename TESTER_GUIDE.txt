====================================================================
LEDGERPULSE v3.0 — USER TESTING, CLOUD SYNC & DEVICE EXCHANGE GUIDE
====================================================================

Thank you for testing LedgerPulse 3.0 (Cross-Platform Auth, LWW Sync & Pulse AI)!

1. WHAT IS INCLUDED IN v3.0
---------------------------
- Cross-Platform User Accounts & Last-Write-Wins (LWW) Cloud Sync:
  * Click "Account / Sync" in the top bar to sign up or sign in via
    Email/Password, Google OAuth, or GitHub OAuth.
  * Automatically attaches all local profiles, categories, transactions,
    and shopping lists to your authenticated User UUID.
  * Syncs across Desktop (Linux/Windows) and Mobile (Android APK) via
    either the Built-in REST/LAN Sync Hub or Supabase Cloud (Postgres RLS)
    with deterministic UTC Last-Write-Wins conflict resolution.
- Interactive Pulse AI Financial Agent:
  * Click "Pulse AI" in the top bar or "Ask Pulse AI" floating button to
    analyze your budget, log expenses in natural language, build itemized
    shopping lists, transfer funds, or attach receipt images.
- Multi-Profile Isolated Accounts:
  * Personal Budget (Household income, rent, groceries, utilities)
  * Business & Consulting (Tax-deductible expenses, SaaS, client revenue)
  * Child's Account (Weekly allowance, gifts, toys, youth savings)
- Local Receipt Scanner & OCR:
  * Drag & drop receipt images or click one of the 4 built-in sample
    receipts to auto-extract Merchant, Date, Total, Tax, and Category.

2. HOW TO RUN ON WINDOWS
------------------------
- Extract "LedgerPulse-3.0-win-x64-portable.zip" to any folder.
- Double-click "Launch-LedgerPulse-Desktop.vbs" (opens in a dedicated
  standalone desktop app window without browser tabs) OR double-click
  "Start-LedgerPulse.bat".
- Prerequisite: Node.js v22.5+ installed on the test machine (uses
  Node's built-in zero-dependency SQLite engine).

3. HOW TO RUN ON LINUX
----------------------
Option A (Portable tar.gz):
  tar -xzf LedgerPulse-3.0-linux-x64.tar.gz
  cd LedgerPulse-3.0-linux-x64
  ./start-ledgerpulse.sh

Option B (Debian / Ubuntu .deb package):
  sudo dpkg -i LedgerPulse-3.0_amd64.deb
  ledgerpulse
